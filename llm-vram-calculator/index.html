Mathematical model and engineering assumptions

Weight & KV-Cache memory equations

Weights_GiB = (Params * 10^9 * BytesPerParam) / 1024^3
KV_GiB = (2 * L * H_kv * D_head * B_kv * Ctx * B_seq) / 1024^3
Total_GiB = Weights_GiB + KV_GiB + (0.8 + 0.06 * Weights_GiB + 0.04 * B_seq)

Where L is layer count, H_kv is Grouped-Query Attention KV head count, D_head is head dimension (128), B_kv is KV byte width, and B_seq is concurrent sequences.

Memory-bandwidth decode throughput

TokPerSec ≈ (0.72 * MemBandwidth_GBs) / (ActiveWeights_GiB + 0.25 * KV_per_seq)

Real-world vLLM and llama.cpp kernels sustain ~65%–78% of theoretical HBM/unified memory bandwidth during decode. Multi-GPU tensor parallelism scales bandwidth with an 0.82 interconnect efficiency factor.

Engineering FAQ

Why does KV-Cache grow so fast with 32K–128K context and concurrency?

Every active sequence allocates Key and Value tensors across every transformer layer for every token in context. Even with Grouped-Query Attention (GQA), running 16 concurrent 64K sequences on a 70B model can consume over 40 GiB in KV cache alone unless FP8 KV quantization is enabled.

How does MoE (Mixture-of-Experts) affect VRAM vs decode speed?

MoE models like Llama 4 Scout 109B or DeepSeek V4.1 Flash 552B must hold all parameters in VRAM, so memory capacity is governed by total parameters. However, token generation only reads the active parameters (17B or 32B) per forward pass, yielding significantly higher decode tok/s on memory-bandwidth-bound GPUs.

Why is Apple Silicon usable VRAM lower than total unified memory?

macOS reserves approximately 25% of unified RAM for the OS kernel and window server by default (configurable via iogpu.wired_limit_mb). A 64GB M4 Max exposes roughly 48GB safely to Metal inference engines like llama.cpp and MLX.

How is the estimated decode tok/s calculated?

Autoregressive decoding at low batch sizes is memory-bandwidth bound. We estimate single-stream throughput using 72% of peak GPU HBM/unified memory bandwidth divided by active model weights plus per-sequence KV-cache reads.
