Centralized pricing source

Every simulator reads from a single versioned file (src/data/pricing-2026.json, currently v2026.11, last verified 2026-11-26). All figures are denominated in USD using published on-demand list pricing for US primary regions.

Calculations run 100% locally in your browser with zero external network calls, zero third-party fonts, and zero analytics trackers.

Engineering boundaries

  • Monthly billing periods use 30 days for token/call volume and 730 hours for continuous GPU instances.
  • GPU VRAM and HNSW index footprints use binary GiB (1024^3 bytes) to match nvidia-smi and Linux RSS metrics.
  • Cloud object storage and egress use decimal TB (1,000 GB) to match AWS S3, Cloudflare R2, Backblaze B2, and GCS invoices.
